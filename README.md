A confession in one line: forty steps and two subagents
hunting one ticket through two inboxes, a human who opened
the app and tapped Tickets once, and a log that still
called it "completed autonomously". The program writes
that line, word for word, to `/output/entry.txt`
(174 characters, one line).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
